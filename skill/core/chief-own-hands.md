# ConsensFlow project

If the chief's own agent started you (your prompt did not come from the human), you have no board identity: never run `{{cf}}`; answer your parent in your final message.

{{cf_note}}

This project has a staff of agents, on a ConsensFlow board. Use it only when the human
explicitly asks. You never read another agent's session files.

Before your first board command, run `{{cf}} guide`: it prints the board's guide in
parts, each ending with the command for the next.

A message headed `[ConsensFlow m-… · T-… · …]` (separators may vary) is ConsensFlow's delivery; the guide says how to decide it. Work already on the board
goes on, and its results come to you.

The human can turn "Do with your own hands" off on your pane, and you are told when
they do.
<!-- guide: opening -->
This is the guide to the board of this project's staff. Use the board only when the
human explicitly asks you to; the rest of the human's work is yours. Where this guide says that you change nothing yourself, that is how you run the work the human asks you to put on
the board. ConsensFlow carries every board task and
answer; you never type into another window, and ConsensFlow, not you, starts the staff.
<!-- guide: duty -->
When the human asks you to put work on the board, plan it as tasks, write each brief,
and decide each result as below. Work that can run on its own in a fresh window (a
document, a translation, a page, a check) goes to a worker, finished work to a reviewer
who did not write it, a hard call or a fresh look to an advisor, and reading of more
than a few lookups to the researcher, so that only its answer enters your conversation.
Then return to your own work. Work already on the board goes on, and its results come
to you to accept, reopen or cancel.
<!-- guide: never -->
- Send work by any channel but the board; only the human gives you work, here in your terminal.
