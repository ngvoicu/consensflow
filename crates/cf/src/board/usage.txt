cf inside a ConsensFlow window: the board's commands.

  cf task add --tier <critical|complex|standard|light> "…"
                                    work for a worker of that tier (--purpose for critical work)
  cf task add --frontend "…"        work for the frontend designer: screens designed, built
                                    and looked at in the project's design language
  cf task add --architect "…"       a design for the architect: docs, contracts and the code's
                                    frame, nothing that runs; for work big enough to need one
  cf task add --research "…"        a question for a researcher: what it found, with its
                                    sources; no file changed
  cf task add --advice --tier <tier> "…"
                                    a question for an advisor of that tier: findings and
                                    recommendations back, no project file changed
  cf task add --review --tier <tier> "…"
                                    a review for a reviewer of that tier: say what to
                                    review; findings back, no project file changed
  cf task add --test --tier <tier> "…"
                                    a test for a tester of that tier: say what to run
                                    and check; results back, no product code changed
  cf task add --integrate "…"       work for the integrator: merge, check, land and clean up
                                    as the project's rules say; no behaviour changed
  cf task add --design "…"          an image from the image designer: what to draw, what
                                    to use as reference, where to save it
  cf task add --after T-3 "…"       a follow-up for the window that did T-3, which
                                    keeps its context; only when that context matters;
                                    until T-3 and the window's done tasks are accepted it waits
  cf task add --self --needs T-3 "…" your own later step: its brief comes back to you when T-3 is accepted
  … --needs T-3,T-4                 the task waits on the board until T-3 and T-4 are accepted
  … --before T-9,T-10               T-9 and T-10 (still on the board) wait for this task
  cf task list [--all]              the board: what waits for a member, then the lanes
                                    with a task to look at; --all adds the idle sessions
  cf task get T-3                   one task and its whole thread
  cf task get T-3 --transcript      what its window did so far (the last 10 items; --last 30 for more)
                                    --page 2 for older ones, 50 a page; --find "…" for those that say it
  cf task done T-3 "…"              finish a task assigned to you (the chief)
  cf task accept|cancel T-3         move a task you asked for
  cf task accept T-3 "…"            accept a failed task you checked; your words are its result
  cf task reopen T-3 "…"            send a finished or failed task back with a follow-up
  cf task edit T-3 "…" [--tier <tier>] [--needs T-4,T-5|+T-5|-T-5] [--before …]
                                    change the brief, tier, needs or before of a task before any window
                                    has its brief (open, queued, or paused): a list replaces, +T-5 adds, -T-5 removes
  cf task pause T-3                 stop a worker's task: the agent stops and its window waits;
                                    what it left running in the background runs on
  cf task resume T-3 "…"            go on with it: the same window, with your words
  cf task edit|reopen|resume T-3 … --title "…"
                                    a new title, in any state (else the brief's first line); edit takes it alone
  cf task finish T-3                take what a working, waiting or paused task's worker said last as its
                                    result; what its turn left running is not ended
  cf tell T-3 "…"                   stop T-3 and put this to its window: its answer arrives as
                                    a message; then cf task resume T-3 "…"
                                    (queued or open: kept for its window, to go in with or after its brief)
  cf tell "…"                       a member tells whoever gave its task; nothing waits
  cf inbox [read m-12]              what is waiting for you, or one message in full
  cf ask "…"                        a question to the chief (a member's; the chief asks the
                                    human in its own terminal)
  cf note "…" [--human]             a note to the human; nothing waits on it
  cf answer m-12 "…"                answer a question put to you
  cf staff                           the members: roles and tiers
  cf whoami                         your project, role and current task
  cf history [--page 2] [--find "…"] [--tools]
                                    the chief's: what the human and the chiefs before you
                                    said, newest page first (after the chief was switched)

Any "…" can be - to read the text from standard input, as written (not PowerShell: use --file):
  cf task add --tier standard - <<'BRIEF'   (then the text, then a line BRIEF)
A long one is surest in a file, which no shell cuts (every command that takes words):
  cf task add --tier standard --file brief.md
task add, reopen, resume, edit and the chief's tell say how many characters went and how the text ends: see that it is all there.

Add --json for machine output.
