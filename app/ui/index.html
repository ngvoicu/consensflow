    Delete this project?

    Its board, staff, sessions, every message and every file ConsensFlow kept for its windows go for good; the trace keeps one line saying it was deleted. This cannot be undone.

    Delete these tasks?

    A deleted task leaves the board and cf task list for good. The ledger keeps it: the chief can still read it, its brief, result and thread, with cf task get. This cannot be undone.
