    The name shows in the list and over the board. The project's folder stays where it is, and so does everything in it.

    Project description

    One line under the project's name in the list, for you alone: no agent is told it. Leave it empty to take it away.

    Delete this project?

    Its board, staff, sessions, every message and every file ConsensFlow kept for its windows go for good; the trace keeps one line saying it was deleted. This cannot be undone.

    Delete these tasks?

    A deleted task leaves the board and cf task list for good. The ledger keeps it: the chief can still read it, its brief, result and thread, with cf task get. This cannot be undone.

      If the chief is in the middle of a turn

        Project staff

        The chief names the tier a task needs and ConsensFlow picks a free member of that tier: a worker does the work, an advisor advises the chief, a reviewer reviews finished work when the chief asks, a tester checks it by running it when the chief asks. An image designer draws: only an image agent is one, and an image agent takes no other role. A member may hold more than one role: one row here per role.

        Wake-up calls

        A chief that stopped while work is left carries on: it is asked whether it still has work to do. Nothing is sent while the project is closed, or while you have typed to the chief and not sent it; its answer stays in its terminal.

        Specs

        With specs on, the chief plans big work as a spec, with Specmint, and puts each phase on the board as tasks; a small ask still goes straight on the board. The app's setting is under Settings, on the Agents screen. A change reaches the chief when it next starts: after Resume, or when you switch the chief.
