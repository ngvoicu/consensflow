Overview

v3 replaces the v2 delegation engine with prose: a generated SKILL.md (Agent Skills format) teaches any coding agent (claude, codex, pi, opencode) to consult the user's named participants by running their exact one-shot CLI commands. ConsensFlow itself shrinks to a zero-dependency npm package: a roster, a skill generator/installer that also manages cmux's own skills, and a minimal ephemeral web UI for the roster. No daemon, no SQLite, no state machine.

Proven before building: the hand-written v0 skill was installed into claude and codex by hand; both runtimes consulted a participant correctly on the first try (codex→diana: DIANA-VIA-SKILL-OK; claude→phoebe: PHOEBE-VIA-SKILL-OK, cross-runtime). All four one-shot command forms verified live 2026-08-19.

Decisions (user, 2026-08-19): skills-first minimal — no engine port; minimal UI for participant management; npm-installable (npm install -g, bins cf + consensflow); ConsensFlow also installs/updates cmux's skills. State root: ~/.config/consensflow/ (override CONSENSFLOW_HOME); v1 roster importable from ~/.consensflow/participants.json.

Acceptance Criteria

  • Roster CRUD works via CLI and survives round-trips; v1 import brings names, models, efforts (pi thinking + preset efforts when v1 presets.js is present).
  • The generated SKILL.md matches the live-verified v0 shape: per-participant exact commands, env -u billing guards, effort flags per engine, full-auto flags only for full-auto participants, names in the description.
  • skills install/update/status/uninstall manage both the consensflow skill and cmux's skills across all detected agents, with a hash manifest; drifted files are never silently clobbered (--force required); uninstall removes only what the manifest owns.
  • Roster changes regenerate and reinstall the consensflow skill everywhere it is installed.
  • cf ui serves a loopback, token-gated single-page roster editor; edits persist and trigger skill regeneration; the process is ephemeral (Ctrl-C).
  • Tests never touch the real HOME/agent dirs (guard), never invoke live agent CLIs or the network (git is PATH-shimmed).
  • npm install -g from the repo yields working cf/consensflow bins with no build step; README covers install on a fresh machine.

Decision Log

2026-08-19Skill-first inversion: v0 SKILL.md hand-written and live-proven on two runtimes before any factory code (advisor).
2026-08-19Zero runtime deps, no build step: plain Node ESM + node:test, so npm install -g works from a git checkout.
2026-08-19env -u ANTHROPIC_API_KEY / OPENAI_API_KEY kept in generated commands: prevents subscription logins silently switching to API billing (v1 dropEnv).
2026-08-19Pane control is cmux's skills' job; the consensflow skill teaches only what to run (v2 lesson: typed-bootstrap verification is a minefield).
